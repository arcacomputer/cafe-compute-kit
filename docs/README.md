- [Contributing](contributing.md): synthetic fixtures, checks and review.
- [Provenance and licensing](provenance.md): AI-assisted work, human stewardship and asset rights.

These guides describe operator actions, not a record of a live deployment. Building a template does not send mail, distribute benefits, publish photos or verify provider redemption. Real attendees, answers, photos, testimonials and code stock are not included. Existing private source repositories and operational records remain private.
